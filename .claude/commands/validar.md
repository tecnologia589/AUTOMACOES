# Comando: Validar

Verifica se os documentos gerados estao completos e conformes.

## Uso
Apos rodar o intake, execute:
```
/validar
```

## Verificacoes
1. Nenhum placeholder {{}} restante nos documentos
2. CPF no formato correto
3. Endereco completo
4. Consistencia entre ficha, contrato, procuracao e declaracao
5. Fonte Montserrat aplicada
